KREATUM · Staging

Información provisional de privacidad

Este documento describe únicamente el tratamiento previsto durante pruebas internas y controladas de KREATUM.

Importante: no introduzcas datos personales reales, información sensible, secretos empresariales ni contenidos de producción.

Alcance del entorno

Staging se utiliza para comprobar flujos, permisos, partidas e informes antes de una puesta en producción. El acceso debe limitarse a personas expresamente autorizadas.

Datos mínimos

Solo deben emplearse datos ficticios o de prueba imprescindibles para validar el funcionamiento. No deben utilizarse categorías especiales de datos ni información que permita identificar a personas reales.

Finalidad

Los datos se usan exclusivamente para pruebas técnicas, de seguridad, experiencia de usuario y calidad de informes. No se utilizarán para decisiones reales, perfiles comerciales ni explotación productiva.

Acceso y seguridad

  • El acceso está restringido a cuentas y participantes autorizados.
  • No compartas códigos de sala, contraseñas, enlaces de invitación, tokens ni secretos.
  • Notifica cualquier acceso inesperado al responsable del entorno.

Conservación

La información de prueba se conservará solo durante el tiempo necesario para validar el entorno, investigar incidencias y cumplir los controles internos aplicables. Después deberá eliminarse o anonimizarse de forma segura.

Responsable y contacto

El entorno está bajo la responsabilidad operativa del equipo designado por GFS. El canal de contacto autorizado debe facilitarse directamente a cada participante de las pruebas.
